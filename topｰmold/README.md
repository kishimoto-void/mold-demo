# TOP Mold Local Starter Pack v0.1

Files:
- `TOP_MOLD_TEMPLATE.md`: local, user-editable personalization contract for the LLM.
- `SESSION_ANALYSIS_TEMPLATE.md`: per-session outcomes, analysis, unknowns (Φ), and next steps.

Suggested use:
1. Keep the TOP profile locally and use a pseudonymous ID.
2. Load only the fields needed for the current task.
3. Keep session reports separate from persistent profile data.
4. At session end (e.g. “今日は終わり”), fill out the session analysis report.
5. Review proposed long-term profile changes before applying them.

Privacy:
- Do not put credentials, API keys, tokens, or unnecessary identifiers in these files.
- A pseudonym does not guarantee anonymity if other identifying details remain.
- These templates do not themselves detect triggers, access GitHub, or save files automatically; those behaviors require a runtime or a workflow that implements them.
